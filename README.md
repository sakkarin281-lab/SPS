# S.P. School Android prototypes

Two Android demonstration apps (WebView and Native) built via GitHub Actions.

See `.github/workflows/build-apks.yml` for automated APK builds. The original source archive is stored as `SP_School_GitHub_APK_Ready.zip` and unpacked during the workflow.

- WebView: opens https://sp-school-v5.vercel.app/#hub
- Native: standalone Android screens for a demonstration of school information

These are demonstration apps, not official school releases. They use debug signing for tests.
